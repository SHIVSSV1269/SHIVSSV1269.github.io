03. Things I've built

Featured · 2026🔒 private · demo on request

Nexa — Voice AI Agent

A voice assistant on the Gemini Live API. Mic audio streams through a WebSocket relay; every tool call is intercepted server-side so the key never touches the client. Safe tools run instantly, risky ones (typing, key presses, closing windows) wait for a spoken "yes". A second, fully offline brain — Whisper, a local tool-calling LLM and Piper on a 4 GB GPU — cut command latency from 4.5s → ~0.6s.
